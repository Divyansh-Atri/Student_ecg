MedGemma Agent

Post-Operative Intelligent Monitoring

AI-powered clinical decision support for post-operative sepsis risk. Combines rule-based early warning scores (NEWS2 + qSOFA) with contextual reasoning from a quantized medical language model — running fully offline on your machine.

MedGemma is fine-tuned on clinical text, radiology reports, and medical literature. The 4-bit quantized version runs on consumer hardware while retaining strong clinical reasoning. All outputs are decision support only — not a substitute for clinical judgment.
